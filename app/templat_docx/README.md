# Templat Word

Taruh berkas templat berita di sini dengan nama **`berita.docx`**
(asal: "13 Oktober Wali - Zoom Meeting.docx").

Arsip Liputan memakai berkas ini untuk ukuran halaman F4, margin, serta gaya **Title** dan **Normal**.
Isi dan gambar contohnya dibuang otomatis saat ekspor.

Selama `berita.docx` belum ada, aplikasi memakai **templat sementara** yang dibuat terprogram
(`app/modul/arsip_liputan/ekspor.py`, fungsi `templat_sementara`) dengan spesifikasi yang sama,
dan setiap ekspor tercatat di Log dengan keterangan "templat sementara".
